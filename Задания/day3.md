# Практика (день 3)

## Добавь в свою историю бой с разминочным противником (без ООП пока — просто переменные), используя циклы:

Задай переменную enemy_health (например, 30).
Сделай цикл while, который работает, пока enemy_health > 0 и health > 0 (бой продолжается, пока оба живы).
Внутри цикла на каждой итерации:
Уменьшай enemy_health на значение strength игрока (это "удар игрока").
Выведи f-строкой, сколько здоровья осталось у противника.
Если enemy_health <= 0 — выведи сообщение о победе и break из цикла.
Иначе уменьшай health игрока на какое-то число (можно фиксированное, например 5 — это "ответный удар противника").
Если после этого health <= 0 — выведи сообщение о поражении и break.
После цикла (то есть когда бой закончился) выведи итоговое сообщение с финальными значениями health и enemy_health.
