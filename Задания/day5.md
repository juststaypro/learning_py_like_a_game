# Тема (день 5): функции

Сейчас весь твой код — это одна длинная последовательность действий сверху вниз. Проблема: если захочешь устроить второй бой (со вторым врагом), тебе придётся скопировать весь блок while целиком. Функции решают это — код пишется один раз, а используется много раз.

## Определение функции:

python
def имя_функции(параметр1, параметр2):
    # тело функции
    return результат   # необязательно, если функция ничего не возвращает

### Пример:

python
def greet(name):
    return f"Привет, {name}!"

message = greet("Hero")
print(message)   # Привет, Hero!

### Параметры могут иметь значения по умолчанию:

python
def take_damage(health, damage=5):
    return health - damage

health = take_damage(30)        # damage не указан — возьмётся 5
health = take_damage(30, 10)    # damage = 10

Важный момент про область видимости (scope). Переменная, созданная внутри функции, недоступна снаружи. А переменная, переданная как параметр — это копия значения, изменения внутри функции не влияют на оригинал (для чисел и строк — для списков/словарей будет отдельный разговор позже, там своя особенность).

python
def try_change(x):
    x = 100
    print("Внутри функции:", x)

number = 5
try_change(number)
print("Снаружи функции:", number)   # всё ещё 5!

Именно поэтому функция боя должна возвращать новые значения здоровья, а не просто "менять" их незаметно:

python
def fight_round(health, enemy_health, hit, strength):
    # логика удара
    return health, enemy_health   # можно вернуть сразу два значения!

## Перепиши свою игру, вынеся бой в функцию:

Создай функцию fight(health, strength, enemy_health, enemy_strength), которая содержит весь твой while-цикл боя внутри себя (входные hit по-прежнему спрашивать через input внутри функции).
Функция должна возвращать три значения: финальное health, финальное inventory (список) и булево значение player_won (True/False — кто победил).
Подсказка: return health, inventory, player_won
В основном коде (снаружи функции) вызови её так:
python
   health, inventory, player_won = fight(health, strength, 30, 10)
После вызова — выведи результат боя и содержимое инвентаря (эта часть кода остаётся снаружи функции, как и была).
