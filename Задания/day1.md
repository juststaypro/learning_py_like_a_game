## Тема: переменные, типы данных, ввод/вывод

### Переменная — это просто имя, за которым хранится значение. В Python не нужно объявлять тип заранее — он определяется автоматически.

python
health = 20          # int — целое число
strength = 16.5      # float — дробное число
name = "Hero"        # str — строка
is_alive = True      # bool — логическое значение (True/False)

### Вывод на экран — функция print():

python
print("Здоровье:", health)

### Ввод от пользователя — функция input(). Важно: она всегда возвращает строку, даже если ввели число.

python
name = input("Введи имя персонажа: ")

### Чтобы превратить строку в число, используются функции-преобразователи:

python
age_str = input("Сколько тебе лет? ")
age = int(age_str)      # теперь это int

### Проверить тип переменной можно функцией type():

python
print(type(health))   # <class 'int'>
