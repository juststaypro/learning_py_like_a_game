## Это твой первый шаг к рюкзаку и списку врагов из задания.

### Список (list) — упорядоченная изменяемая коллекция:

python
inventory = ["меч", "зелье здоровья", "щит"]
inventory.append("свиток силы")   # добавить в конец
inventory.remove("щит")           # удалить по значению
first_item = inventory[0]         # доступ по индексу (с 0!)
print(len(inventory))             # количество элементов

### Словарь (dict) — хранит пары "ключ: значение", удобен, когда у предмета есть несколько характеристик:

python
sword = {"name": "меч", "damage": 15, "type": "оружие"}
print(sword["damage"])     # 15 — доступ по ключу
sword["damage"] = 20       # изменить значение
sword["durability"] = 100  # добавить новый ключ

### Список словарей — это уже почти рюкзак:

python
inventory = [
    {"name": "меч", "type": "оружие", "damage": 15},
    {"name": "зелье", "type": "еда", "heal": 10},
]
for item in inventory:
    print(item["name"], "-", item["type"])
